How I work with Claude

The AI assistant in every project

Claude is an AI assistant. I use it to draw design options side by side and to check finished work against rules I wrote for each project.

I work this way because comparing real options leads to better decisions than debating one. The decisions stay mine, and no change goes live without my approval.

My Claude kit

The AI tools I use, in plain words

Helpers I wrote, each with one job

  • Rule guardHaikuChecks every change against the project’s written rules before anyone reviews it.
  • VerifierHaikuRuns the automated tests and reports only what failed.
  • BreakerOpusTries to break a finished change, so problems show up before users find them.
  • WalkerOpusTaps through the real app on a simulated phone and reports what it sees.
  • ScribeSonnetRecords each decision in the project’s rules once a change is accepted.

Claude Code, the coding version

  • Custom subagentsThe helpers above.
  • Custom skillsSaved instructions for tasks I repeat.
  • Plan, then buildA written plan I approve before any code.
  • Git worktrees for parallel sessionsSeparate copies of the code, so two tasks never collide.
  • HooksAutomatic checks that run at set moments.
  • MemoryNotes that carry over from one session to the next.
  • Project rulesThe decisions every change has to follow.
